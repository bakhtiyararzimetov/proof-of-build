# Roadmap

## v1.0 — Hackathon MVP (current)
- [x] Anchor program: prize vault, deposits, teams, registration window
- [x] Daily on-chain fires from verified GitHub commits
- [x] Winners with shares, automatic fair split, batched finalize, claim, sweep
- [x] On-chain disqualification with a reason hash
- [x] GitHub App oracle: HMAC webhooks, 8 fraud flags, webhook redelivery
- [x] Web app: organizer flow, team dashboard, admin panel, leaderboard
- [x] Certificates with on-chain hash and public verification
- [x] Installable mobile app (PWA)
- [x] Devnet deployment, 53 contract tests, 41 backend tests

## v1.1 — Public Beta
- [ ] Permanent hosting (Vercel + Render/Railway)
- [ ] Android APK
- [ ] Email notifications for missed days
- [ ] Organizer analytics: activity per day, per team

## v2.0 — Mainnet
- [ ] Security audit of the program
- [ ] Mainnet deployment with real USDC
- [ ] Several independent oracles (threshold signing) instead of one key
- [ ] On-chain judge voting

## v3.0 — Ecosystem
- [ ] GitLab and Bitbucket support
- [ ] Sponsor bounties per track
- [ ] Builder reputation from past hackathons
- [ ] Integrations with Colosseum and university programs
